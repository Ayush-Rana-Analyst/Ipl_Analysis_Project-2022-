 IPL 2022 Dataset

📌 Overview  
This repository contains the IPL 2022 match dataset with detailed information about matches, venues, scores, players, and performances.  
It can be used for sports analytics, visualization projects, and machine learning experiments.

📂 File Contents  
- **IPL.csv** → Match‑wise data including:  
  - Match ID, Date, Venue  
  - Teams, Toss details  
  - Scores (1st & 2nd innings)  
  - Match winner, Margin, Player of the Match  
  - Top scorer & Best bowling figures  

🔧 Tools & Usage  
You can use this dataset with:  
- Python (Pandas, Matplotlib, Seaborn) for data analysis & visualization  
- Power BI / Tableau for dashboards  
- Excel for quick summaries  

🎯 Example Ideas  
- Team performance comparison  
- Player of the Match analysis  
- Toss decision impact  
- Highest run scorers & best bowlers
